# 郜中强个人作品集

本项目为个人作品集的本地版本，包含教育经历、校园与实习经历、专业能力、两个生物医药信息产品案例以及联系表单。

## 本地预览

在当前目录启动静态服务器后访问页面：

```bash
python -m http.server 3003
```

```text
http://127.0.0.1:3003/
```

## 联系表单

页面通过 `mailto:` 生成邮件草稿，由访问者确认后发送。该方案适用于 GitHub Pages，不需要在公开仓库中保存邮箱密码或授权码。

若访问者的设备没有配置默认邮件客户端，页面会提示其复制左侧邮箱或联系方式进行沟通。
