# 医药情报台 Web 工作台

这是把原本的本地自动化脚本升级为网页产品形态的第一版原型。它不是作品集展示页，而是给内容运营人员使用的交互式工作台。

## 这一版解决什么

- 把自动检索后的资讯放入候选池，支持按主题、关键词、核验状态筛选。
- 点击资讯后展示运营摘要、原始来源、为什么需要人工核验。
- 支持把候选资讯加入日报，并实时生成日报文本预览。
- 支持对单条资讯做“重点关注 / 可做选题 / 无需关注”反馈。
- 反馈不会直接决定推送，而是进入偏好权重和人工复核逻辑，避免恶意反馈污染规则。
- 当前表格工作台支持动态指标、批量加入日报、批量设为可发、批量标记核验、结构化日报分区和本地反馈学习记录。
- 当前 Web 原型已从单一页面升级为多视图工作台，包含候选审核、日报编排、反馈分析、来源规则和历史日报。

## 如何打开

双击项目根目录下的 `打开网页工作台Demo.bat`。

也可以直接打开：

`biomed_radar_web/index.html`

## 后续如何接入真实项目

这一版先做交互原型，后续可以分三步接入真实系统：

1. 后端数据层：把 `auto_news_cn.xlsx` 逐步迁移到 SQLite 数据库。
2. 检索层：让现有 Python 检索脚本定时写入数据库。
3. 网页层：把当前静态样例数据替换为本地服务接口，展示真实候选、真实日报、真实反馈。

## 产品原型文档

- `PRODUCT_PROTOTYPE_BLUEPRINT.md`：说明产品定位、目标用户、核心场景、MVP 范围和版本路线。
- `LOW_FIDELITY_WIREFRAME.md`：说明候选审核、日报编排、反馈学习和历史日报的低保真页面结构。
- `DATA_ARCHITECTURE.md`：说明从 Excel 迁移到 SQLite 时建议采用的数据表和数据流。
- `UI_REDESIGN_NOTES.md`：说明为什么撤掉装饰图，改为成熟 B 端工作台界面。
- `BIOMED_RADAR_DESIGN_PROMPT.md`：把参考提示词转化成中文语境下的资讯雷达设计规范。

## 自审标准

- 是否像一个可使用的运营工具，而不是作品集海报。
- 是否减少大卡片堆叠，优先使用列表、详情、预览和状态反馈。
- 是否能完成核心流程：筛选、审核、加入日报、反馈、导出。
- 是否符合当前国内产业资讯偏好。
- 是否没有泄露邮箱、授权码、后台密钥等敏感信息。
