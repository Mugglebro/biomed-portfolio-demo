# BioEvent Intelligence 实施检查清单

## 禁用业务词检查

- 页面可见内容中不出现：已报名确认、报名确认号、订单编号、取消报名、选择票种、支付、入场二维码、下载确认函、官方认证主办方。
- 报名按钮统一为“前往原始报名页面”。
- 报名说明统一为“将跳转至主办方或原始发布渠道，报名结果以对方页面为准。”

## 无站内报名检查

- 不创建站内报名表单；
- 不创建支付、订单、票种、确认或入场流程；
- 所有报名动作只跳转外部链接。

## 数据结构检查

- `activities`、`articles`、`sources`、`organizers`、`activityUpdates`、`activityArticleLinks` 集中定义；
- TypeScript 类型覆盖核心实体；
- 活动与文章通过关联表表达多来源聚合；
- 活动包含首次发现时间、最近确认时间、来源数量、文章数量和去重说明。

## 来源追溯检查

- 活动详情可打开来源抽屉；
- 来源抽屉展示文章标题、来源名称、发布时间、文章性质、原文链接和抽取字段；
- 不展示内部模型版本、置信度解释或虚构认证。

## 更新记录检查

- 活动详情展示更新时间线；
- 更新记录关联支撑文章；
- 通知抽屉来自活动更新记录。

## localStorage 检查

- 收藏活动可持久化；
- 工作标签可持久化；
- 备注可持久化；
- 通知已读状态可持久化；
- 筛选条件和排序方式可持久化；
- 无登录状态依赖。

## 响应式检查

- 首页、详情页、日历页、我的活动页和主办方详情页在移动端不横向溢出；
- 顶部导航在窄屏可换行或压缩；
- 抽屉在移动端占满宽度。

## 无障碍检查

- 所有按钮有可读文本或 `aria-label`；
- 抽屉可通过关闭按钮关闭；
- 表单控件有可见标签；
- 链接使用明确文案；
- 焦点样式清晰。

## 验证命令

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`

## 公开部署检查

- 页面标注“当前为演示数据快照”；
- 无需后端即可运行；
- 外部链接使用新窗口打开；
- 可部署至 Vercel、Netlify 或静态托管平台；
- 作品集入口可直接链接到首页。
