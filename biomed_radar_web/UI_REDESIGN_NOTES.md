# UI 重构说明

## 本次设计判断

当前项目不是营销页，也不是单纯作品集页面，而是一个内容运营工作台。因此视觉目标不是“炫”，而是让使用者快速完成工作。

## 撤掉的设计

- 撤掉 AI 生成的科技雷达大图。
- 撤掉偏展示页的首屏大视觉。
- 减少大块装饰卡片，保留真正承载信息的面板。

## 当前采用的界面语言

- 参考成熟 B 端后台的结构：左侧导航、顶部状态、主列表、右侧详情、底部预览。
- 使用克制配色：浅灰背景、白色工作区、深色导航、绿色作为唯一强调色。
- 强化操作路径：筛选候选、查看核验、加入日报、记录反馈。
- 将“好不好看”转为“能不能用”：每个区域必须对应真实运营动作。

## 继续优化方向

1. 用 Figma 或 Pixso 先画低保真流程图，再做高保真样式。
2. 如果进入真正开发版，建议使用 Ant Design、Semi Design 或 TDesign 这类成熟组件库。
3. 接入真实数据后，优先补充表格排序、批量操作、详情抽屉、日报版本记录。
4. 作品集展示时，只展示脱敏样例数据和产品思考，不暴露真实邮箱、授权码和内部数据。

## 自审问题

- 是否一眼能看出这是资讯运营工具？
- 是否能完成候选筛选、审核、编排、反馈四个动作？
- 是否避免了无意义的大图和空泛科技感？
- 是否符合国内创新药产业事件的资讯偏好？
- 是否足够像产品岗/运营岗能讲清楚的项目？
