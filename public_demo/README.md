# 医药情报台

这是一个用于求职作品集展示的静态网页 Demo。

它展示的是一个面向内容运营场景的医药产业资讯工作台：从候选资讯筛选、风险核验、日报编排到反馈复盘，模拟运营人员每天处理产业资讯的核心流程。

当前 Demo 使用脱敏样例数据，不包含真实邮箱、授权码、内部表格、运行日志或后台配置。

## 当前内容偏好

- 中国创新药
- NMPA / CDE
- BD / 授权 / 出海
- 融资并购
- ADC / 双抗 / 细胞治疗等产业事件
- 商业化 / 医保 / 集采
- 上市公司公告

## 不重点关注

- 泛科研论文
- 基础生物医学研究
- 会议论坛
- 白皮书
- 单纯趋势解读
- 无明确事件的新闻稿
