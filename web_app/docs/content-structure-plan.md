# BioEvent Intelligence 内容结构规划

## 活动发现页

页面目标是让访问者先理解“这是一套活动情报索引”，再进入检索。

内容顺序：

1. 首屏：品牌、情报库编号、短价值句、核心数据和脱敏来源动态。
2. 最新收录：展示 3 条有图活动，强调活动本身，不解释功能。
3. 活动检索：筛选条件和筛选结果必须连续出现，不被其他模块打断。
4. 活动索引：展示去重后的结果列表，列表项包含图片、日期、状态、主办方、来源数量和详情入口。

文案规则：

- 少用“用于展示”“演示版展示”等解释语。
- 只保留必要的“演示数据快照”提示，放在轻量元信息位置。
- 活动卡片使用真实业务字段：日期、城市、主办方、来源数、文章数、最近确认。
- 避免过多句号，标题和标签不用句号。

## 活动详情页

页面目标是解释一场活动如何由多来源聚合而成。

内容顺序：

1. 活动核心信息。
2. 外部报名入口，使用轻量模块。
3. 来源追溯。
4. 更新记录。
5. 收藏、标签和备注。

报名入口规则：

- 主按钮文案为“前往原始报名页面”。
- 不出现站内报名、确认号、订单、票种或二维码。
- 可展开查看原始渠道、链接类型和跳转说明。

## 行业日历

页面目标是按时间浏览活动密度。

内容重点：

- 月份切换。
- 当月活动列表。
- 活动状态和城市。

## 我的活动

页面目标是展示当前浏览器中的本地工作清单。

内容重点：

- 收藏活动。
- 工作标签。
- 备注。
- localStorage 边界说明简短呈现。

## 主办方详情

页面目标是让访问者理解同一主办方的活动轨迹。

内容重点：

- 主办方类型。
- 主题和城市偏好。
- 近期关联活动。
- 公开渠道。
