# 生物医药产业资讯雷达 Web 化规划

## 1. 产品定位

这是给内容运营人员使用的产业资讯工作台，不是作品集介绍页。它要把“自动检索到一堆候选资讯”变成“运营人员可以快速判断、筛选、编排、反馈、复盘”的日常工具。

## 2. 用户每天要完成的任务

1. 查看系统自动检索到的候选资讯。
2. 按国内产业事件偏好筛掉低价值内容。
3. 查看每条资讯为什么被推荐，以及为什么需要人工核验。
4. 将合适内容加入当日日报。
5. 对资讯质量做反馈，让规则逐步学习。
6. 生成日报并进入邮件推送流程。

## 3. 第一版网页模块

- 候选池：展示今日候选，支持分类、关键词、核验状态筛选。
- 审核详情：展示摘要、来源、评分、核验原因和原始链接。
- 日报编排：把选中的资讯实时生成日报文本。
- 反馈学习：记录“重点关注 / 可做选题 / 无需关注”，影响主题权重。
- 自审清单：提醒当前版本是否满足运营工具的基本要求。

## 4. 内容偏好

优先关注中国创新药产业事件，尤其是 NMPA / CDE、BD 授权出海、融资并购、ADC / 双抗 / 细胞治疗、商业化 / 医保 / 集采、上市公司公告。

不重点关注泛科研论文、基础生物医学研究、会议论坛、白皮书、单纯趋势解读和无明确事件的新闻稿。

## 5. 设计原则

- 首页直接进入工作台，不做营销式大标题。
- 用列表、分栏、状态和详情面板承载信息，减少大卡片堆叠。
- 每个“需核验”都必须写清楚原因。
- 反馈要自然，不让收件人一条资讯发一封邮件。
- 页面可以被招聘方观看，但核心仍然是产品原型。

## 6. 迭代路线

1. 静态交互原型：验证页面结构、筛选流程、反馈方式。
2. 数据接入版：Python 自动检索后输出 JSON，网页读取真实候选。
3. 数据库版：SQLite 保存候选、日报、反馈、推送记录。
4. 本地服务版：用轻量 Flask / FastAPI 提供网页接口。
5. 在线演示版：发布脱敏数据，避免泄露邮箱、授权码和内部信息。
